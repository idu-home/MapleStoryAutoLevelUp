项目的核心原理是**计算机视觉（Computer Vision, CV）**。它不断地截取游戏窗口的画面，然后通过图像识别技术来理解当前游戏发生了什么。这就像一个不知疲倦的人，一直盯着屏幕，找出需要关注的信息。

### 2. 如何决策角色行为？

决策是在 `MapleStoryAutoBot` 类的主循环 `loop` 中进行的。这个循环的核心是一个**有限状态机（Finite State Machine, FSM）**。简单来说，角色在任何时候都处于一个明确的“状态”中，比如“打怪中”、“寻路中”、“解符文中”等等。根据当前的游戏状态（比如，看到符文了、血量低了、没怪可打了），状态机会从一个状态切换到另一个状态，并执行相应的动作。

这里定义了几个状态：
*   `HuntingState`：主要的打怪状态。
*   `FindingRuneState`：看到符文出现提示后，开始寻找符文的状态。
*   `NearRuneState`：靠近符文之后的状态。
*   `SolvingRuneState`：进入解符文界面后的状态。
*   `PatrolState`：巡逻状态，可能是在没有怪物时移动。
*   `AuxiliaryState`：辅助状态，可能用于处理一些特殊情况。

并且定义了状态之间合法的转换关系。例如，`hunting` 状态可以转换到 `finding_rune` 状态，这是当屏幕上出现“Rune has created”消息时触发的。

每个状态的具体逻辑定义在 `src/states/` 目录下的对应文件中。例如，`hunting.py` 中会包含打怪的逻辑：寻找最近的怪物，然后移动过去并攻击。

### 总结与安全风险分析

**工作流程总结:**

1.  **感知 (Perception)**: `GameWindowCapturor` 模块持续截取游戏窗口画面。`MapleStoryAutoBot` 类中的各种 `get_*` 方法（如 `get_nearest_monster`, `get_player_location_on_global_map`）利用计算机视觉在截图上识别游戏元素，从而构建对当前游戏世界的理解。
2.  **决策 (Decision-Making)**: `FiniteStateMachine` (FSM) 是决策核心。基于从“感知”阶段获得的信息，FSM 在不同状态（`Hunting`, `SolvingRune` 等）之间切换。每个状态定义了在该情境下应该执行的行为。
3.  **行动 (Action)**: `KeyBoardController` 模块负责执行决策。它接收来自 FSM 的指令（如 "move left", "attack"），并将其转换为模拟的键盘按键，发送给游戏窗口。

**潜在后门和安全风险分析:**

从代码结构和实现原理来看，这个项目本身作为游戏自动化脚本，其主要目的是模拟玩家操作，**并没有明显的主观恶意的后门**。它不涉及修改游戏客户端、拦截网络数据包或注入恶意代码。它的所有操作都是通过模拟用户输入（截图和按键）完成的，这是一种相对“干净”的自动化方式。

然而，任何执行代码的程序都存在潜在风险，我们可以从以下几个角度分析：

1.  **依赖库风险 (Supply Chain Attack)**: 项目依赖了多个第三方 Python 库（见 `requirements.txt`）。如果这些库的任何一个被恶意行为者攻破（例如，在某个版本中被注入了恶意代码），那么运行这个脚本就可能导致你的计算机被感染。这是一个普遍存在于所有开源项目中的供应链风险，并非此项目独有。信任 `opencv-python`, `numpy`, `pynput` 等知名库通常是比较安全的，但风险理论上存在。
2.  **非预期的行为**: 由于脚本是基于图像识别的，当游戏界面发生微小变化（例如，UI更新、弹窗、或者被其他窗口遮挡），可能会导致识别错误，从而做出非预期的操作。虽然 `KeyBoardController` 会检查游戏窗口是否为激活状态，但如果脚本逻辑出错，在极少数情况下，它可能会在非预期的窗口（如你的聊天软件、命令行终端）中输入字符。这虽然不是“后门”，但可能导致一些尴尬或无意的破坏性操作。
3.  **无远程执行能力**: 我检查了代码，没有发现它包含任何监听网络端口、接受远程命令或将你的数据上传到外部服务器的功能。这意味着它不具备被远程控制的“后门”特性。它是一个纯粹的本地自动化工具。
4.  **配置文件与路径操作**: 脚本会读取本地的配置文件（`.yaml`）和地图/怪物图片。如果有人诱导你使用一个恶意的配置文件或图片文件，理论上可能通过构造特殊的路径（例如 `../../...`）来尝试访问或覆盖你系统上的其他文件。但从代码实现来看，它主要是拼接路径，直接利用这种方式进行攻击的难度较大且需要特定条件。
